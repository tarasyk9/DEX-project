# AccessManager

[Git Source](https://github.com/tarasyk9/DEX-project/blob/65533ada8ce86eea939855b5e7715733e43cbc6f/src/AccessManager.sol)

**Inherits:** AccessControl

**Title:** Access Manager

Role management contract for the DEX protocol

<i>

Uses OpenZeppelin AccessControl to manage administrator,
multisig administrator, and EIP-712 swapper roles.

</i>

## Functions

<a id="constructor"></a>

### constructor

Initializes the access manager

```solidity
constructor();
```

<a id="addadmin-address"></a>

### addAdmin

Grants the protocol administrator role to an account

```solidity
function addAdmin(address _admin) external onlyRole(DEFAULT_ADMIN_ROLE);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _admin | `address` | Address that will receive the administrator role |

<a id="removeadmin-address"></a>

### removeAdmin
