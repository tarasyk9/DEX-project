## State Variables

### quorum

The number of signers required to execute a transaction

```solidity
uint256 public quorum;
```

### transfersCount

The number of transfers executed

```solidity
uint256 public transfersCount;
```

### transfers

The mapping of transfer IDs to transfer details

```solidity
mapping(uint256 => Transfer) private transfers;
```

### multisigSigners

The mapping for verification that address is a signer

```solidity
mapping(address => bool) private multisigSigners;
```

## Structs

### Transfer

The struct of a transfer

```solidity
struct Transfer {
        address to;
        uint256 amount;
        uint256 approvals;
        bool executed;
        mapping(address => bool) approved;
    }
```

**Properties**

| Name | Type | Description |
| ---- | ---- | ----------- |
| to | `address` | The address of the recipient |
| amount | `uint256` | The amount of tokens to transfer |
| approvals | `uint256` | The number of approvals required to execute the transfer |
| executed | `bool` | Whether the transfer has been executed |
| approved | `mapping(address => bool)` | The mapping of signers to their approval status |
