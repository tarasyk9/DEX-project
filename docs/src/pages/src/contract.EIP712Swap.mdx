# EIP712Swap

[Git Source](https://github.com/tarasyk9/DEX-project/blob/65533ada8ce86eea939855b5e7715733e43cbc6f/src/EIP712Swap.sol)

**Inherits:** EIP712

**Title:** EIP-712 Swap Executor

Allows users to authorize token swaps using EIP-712 typed-data signatures

## Constants

### SWAP_TYPEHASH

EIP-712 type hash used when hashing SwapRequest structures

```solidity
bytes32 private constant SWAP_TYPEHASH = keccak256(
        "SwapRequest(address pool,address sender,address tokenIn,address tokenOut,uint256 amountIn,uint256 minAmountOut,uint256 nonce,uint256 deadline)"
    );
```

## State Variables

### _nonces

Stores the current nonce for each swap signer

```solidity
mapping(address => uint256) private _nonces;
```

## Functions

<a id="constructor"></a>

### constructor

Initializes the EIP-712 signing domain

<i>

Uses "EIP712Swap" as the domain name and "1" as the domain version

</i>

```solidity
constructor() EIP712("EIP712Swap", "1");
```

<a id="verify-iswap-swaprequest-bytes"></a>

### verify

Verifies an EIP-712 signature for a swap request

```solidity
function verify(ISwap.SwapRequest memory _swapRequest, bytes memory _signature) public view returns (bool);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _swapRequest | `ISwap.SwapRequest` | Swap request that was signed by the user |
| _signature | `bytes` | EIP-712 signature associated with the request |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `bool` | True if the recovered signer matches the request sender |

<a id="executeswap-iswap-swaprequest-bytes"></a>

### executeSwap

Executes a swap authorized by an EIP-712 signature

```solidity
function executeSwap(ISwap.SwapRequest memory _swapRequest, bytes memory _signature) public returns (bool);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _swapRequest | `ISwap.SwapRequest` | Signed swap request containing pool and swap parameters |
| _signature | `bytes` | EIP-712 signature produced by the request sender |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `bool` | True when the swap has been successfully executed |

## Errors

### InvalidSignature

Thrown when the recovered signer does not match the request sender

```solidity
error InvalidSignature();
```

### ExpiredSwapRequest

Thrown when a signed swap request has expired

```solidity
error ExpiredSwapRequest();
```

### InvalidNonce

Thrown when the supplied nonce does not match the sender's current nonce

```solidity
error InvalidNonce();
```
